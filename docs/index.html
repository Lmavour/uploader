01

Quick start

Videy is the adapter exposed in the browser playground because its API advertises cross-origin upload support. Send a multipart request with a single file field.

POST https://videy.co/api/upload 
curl -X POST https://videy.co/api/upload \
  -F "file=@./clip.mp4"
const form = new FormData();
form.append("file", file);

const response = await fetch(
  "https://videy.co/api/upload",
  { method: "POST", body: form },
);

if (!response.ok) throw new Error("Upload failed");

const { id } = await response.json();
const url = `https://cdn.videy.co/${id}.mp4`;
import { Videy } from "@zanixongroup/uploader";
import { readFile } from "node:fs/promises";

const file = await readFile("./clip.mp4");
const url = await Videy(file);

console.log(url);
02

Request contract

Use multipart/form-data. The browser generates the boundary; do not set the Content-Type header manually when using FormData.

FieldTypeRequiredDescription
file Binary Yes An MP4 or MOV file smaller than 1 GB.

File limits shown here mirror the package adapters. Hosting providers can change limits, retention policies, or availability independently.

05

Errors and boundaries

Validate early, surface provider errors, and never assume an upstream service is available. The playground covers the most common failure modes.

400Invalid requestMissing file or unsupported payload.
413Payload too largeThe selected file exceeds the provider limit.
CORSBrowser policyUse a browser-enabled adapter or call the package from Node.js.
5xxProvider unavailableRetry later or select another adapter server-side.
Good to know

Before you ship.

Does this website store my file?

No. The live request is sent directly from your browser to Videy. This static website has no upload server or database.

Why is only Videy available in the browser playground?

Browser requests require an upstream CORS policy. The remaining package adapters are intended for Node.js, where browser cross-origin restrictions do not apply.

Are hosted files guaranteed to remain forever?

No client library can guarantee a third-party provider's future retention or availability. Review the selected provider's current policy before storing critical files.
